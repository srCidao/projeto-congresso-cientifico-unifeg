Requisitos:
Python 3.9
Instalar dependências no cmd no o comando: pip install -r requirements.txt

| Biblioteca                | Função principal                                |
| ------------------------- | ----------------------------------------------- |
| **opencv-python** (`cv2`) | Captura de vídeo da webcam e exibição do feed.  |
| **mediapipe**             | Rastreamento das mãos e detecção dos dedos.     |
| **pyautogui**             | Movimento e controle do cursor do mouse.        |
| **numpy**                 | Cálculos matemáticos e suavização de movimento. |
| **pygame**                | Engine gráfica e lógica do jogo.                |
